## About Me

I'm a software engineer who builds things that **actually work** — from intelligent automation pipelines and native Android apps to full-stack web platforms. I focus on writing clean, maintainable code that solves real problems efficiently.

- **Automation** — process automation, scripting, workflow orchestration, bots
- **Android Development** — native Android apps (Java/Kotlin + Python via Kivy/BeeWare)
- **Full-Stack Web** — end-to-end web apps, REST APIs, databases, deployment
- **Python** — my go-to language for automation, backends, scripts, and tooling
